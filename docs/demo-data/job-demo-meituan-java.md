# 美团后端开发校招 JD（脱敏演示版）

## 公司

美团（公开招聘信息风格脱敏示例）

## 岗位

后端开发工程师 - 校招

## 城市

上海 / 北京 / 成都

## 岗位类型

校招

## 技术方向

Java 后端、交易系统、业务中台

## 岗位职责

- 参与交易、订单、库存、营销等业务系统建设。
- 负责后端接口开发、数据库设计和服务稳定性优化。
- 参与容量评估、性能压测、慢 SQL 治理和线上问题排查。
- 推动工程质量提升，包括代码规范、单元测试和文档沉淀。

## 任职要求

- Java 基础扎实，理解面向对象、异常、集合和并发编程。
- 熟悉 Spring Boot 或 Spring Cloud 生态。
- 熟悉 MySQL、Redis，理解常见性能问题和优化方案。
- 具备良好的问题分析能力和沟通协作能力。
- 至少完成一个有业务闭环的后端项目。

## 加分项

- 有电商、交易、订单、库存项目经验。
- 了解 RabbitMQ、Kafka 等消息中间件。
- 有接口压测、缓存一致性或数据库索引优化经验。

## 技术关键词

Java、Spring Boot、Spring Cloud、MySQL、Redis、RabbitMQ、订单系统、库存一致性、缓存一致性、压测、慢 SQL。
