# 模拟面试复盘（脱敏演示版）

## 面试场景

- 岗位：Java 后端开发实习生
- 方向：项目深挖 + Java 基础 + Redis / MySQL
- 面试时长：45 分钟

## 表现较好的部分

- 能较清楚说明 zyagent 项目的业务闭环和技术架构。
- 对 Spring Boot、Redis 缓存和 MySQL 索引有基本理解。
- 能说明订单项目中的库存扣减、分布式锁和消息队列异步处理。

## 暴露的问题

### 项目表达不够量化

描述“优化了接口性能”，但没有马上说出优化前后指标、压测方式和数据来源。

改进：

- 准备固定表达：优化前平均 900ms，优化后约 120ms。
- 说明如何定位慢 SQL，如何设计联合索引。

### Redis 分布式锁细节不足

能说出 `SET NX PX`，但 Lua 释放锁、锁续期和业务超时边界说得不完整。

改进：

- 补充唯一 value 的意义。
- 说明释放锁为什么需要原子校验。
- 准备 Redisson 看门狗机制的基本解释。

### JVM 回答偏概念化

能列出内存区域，但对 GC Roots、可达性分析和常见垃圾收集器掌握一般。

改进：

- 用一页笔记整理 GC Roots 类型。
- 准备一次 OOM 排查案例表达。

## 下一步学习计划

### 第 1-2 天

复习 Redis 缓存问题、分布式锁、缓存一致性，整理 10 个高频问答。

### 第 3-4 天

复习 MySQL 索引、事务、锁、MVCC，结合订单项目准备慢 SQL 优化讲解。

### 第 5 天

复习 JVM 内存区域、GC Roots、垃圾收集器和 OOM 排查。

### 第 6 天

围绕 zyagent 和 GGmall 各准备 5 个项目追问。

### 第 7 天

进行一次完整模拟面试，输出复盘报告并更新简历表达。
