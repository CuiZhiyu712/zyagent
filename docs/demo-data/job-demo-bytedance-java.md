## 岗位职责

- 参与核心业务后端系统设计、开发和维护。
- 负责高并发接口、数据存储、缓存和消息队列相关开发。
- 与产品、前端、测试协作，保障需求高质量交付。

## 任职要求

- 熟悉 Java 基础、集合、多线程、JVM。
- 熟悉 Spring Boot、MyBatis 等常见后端框架。
- 熟悉 MySQL 索引、事务、锁和 SQL 优化。
- 熟悉 Redis 缓存设计，了解缓存穿透、击穿、雪崩。
- 了解计算机网络、操作系统、数据结构和常见算法。
- 有完整后端项目经验，能清楚说明业务背景、技术难点和优化结果。

## 加分项
