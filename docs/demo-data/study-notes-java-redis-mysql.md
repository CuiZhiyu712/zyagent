# Java / Redis / MySQL 高频面试笔记（脱敏演示版）

## Java 基础

### HashMap 扩容

HashMap 默认负载因子是 0.75。容量达到阈值后会扩容为原来的 2 倍。JDK 8 中链表长度超过阈值且数组容量达到 64 后会转为红黑树。

常见追问：

- 为什么容量通常是 2 的幂？
- hash 扰动函数有什么作用？
- 红黑树化为什么需要容量达到 64？

### JVM 内存区域

主要包含堆、虚拟机栈、本地方法栈、程序计数器、方法区。

面试表达：

- 堆存放对象实例，是 GC 重点管理区域。
- 虚拟机栈存放栈帧，包括局部变量表、操作数栈、动态链接和返回地址。
- 程序计数器记录当前线程执行的字节码行号。

## Redis

### 缓存穿透

请求查询的数据在缓存和数据库中都不存在，导致请求直接打到数据库。

解决方案：

- 缓存空值并设置短 TTL。
- 使用布隆过滤器过滤明显不存在的 key。
- 对接口做参数校验。

### 缓存击穿

某个热点 key 过期，大量请求同时访问数据库。

解决方案：

- 热点 key 设置逻辑过期。
- 使用互斥锁，只允许一个线程重建缓存。
- 提前异步刷新热点缓存。

### 缓存雪崩

大量 key 同时过期或 Redis 故障，导致请求集中打到数据库。

解决方案：

- TTL 增加随机值。
- 多级缓存。
- 限流、降级、熔断。
- Redis 高可用部署。

### 分布式锁

Redis 分布式锁常用 `SET key value NX PX timeout` 实现。

注意点：

- value 要唯一，释放锁时校验 value。
- 使用 Lua 脚本保证判断和删除的原子性。
- 锁超时时间需要覆盖业务执行时间。

## MySQL

### 索引失效场景

- 对索引字段使用函数。
- 左模糊查询，例如 `%abc`。
- 隐式类型转换。
- 联合索引不满足最左前缀原则。
- OR 条件中存在未索引字段。

### 事务隔离级别

- 读未提交：可能脏读。
- 读已提交：解决脏读，可能不可重复读。
- 可重复读：MySQL InnoDB 默认级别，解决不可重复读。
- 串行化：隔离最强，性能最低。

### MVCC

MVCC 通过版本链和 ReadView 实现一致性读。每行记录有隐藏字段，包括事务 id 和回滚指针。不同隔离级别下 ReadView 创建时机不同。

面试表达：

- 读已提交每次查询生成新的 ReadView。
- 可重复读在事务第一次查询时生成 ReadView。
- 当前读会加锁，不走普通快照读。
